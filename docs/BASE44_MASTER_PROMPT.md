# Base44 Master Prompt v0.1 — Zodiac Battlegrounds

Build a responsive web game prototype named Zodiac Battlegrounds. This must be a REAL playable prototype, not a static UI mockup.

Phase 1 scope: two original playable zodiac fighters (Aries and Scorpio), single-player against a bot, one arena, real-time movement and combat. Provide keyboard and touch controls. Implement attacks, block, dodge, health, energy, cooldowns, collision/hit detection, victory/defeat and restart. Keep game loop independent from Base44 persistence. Use Phaser only if dependencies and runtime are supported; otherwise report the blocker rather than pretending the game works.

Create character-selection screen, game screen, results screen, settings and an admin-facing configuration view. Store character definitions and five evolution tiers (Warrior, Awakened, Celestial, Divine, Omega). Only Warrior abilities need to be playable in Phase 1; clearly mark later tiers as planned. Design all 12 zodiac archetypes in data without claiming they are playable.

Implement actual bot behavior, not a scripted fake match. Avoid fabricated PvP, leaderboards or user counts. Ensure touch targets, responsive scaling, reduced-motion option, and basic keyboard accessibility.

Deliver an honest feature checklist: implemented, tested, blocked, planned. Provide test steps and known limitations. Do not claim Roblox publishing or production multiplayer is supported by Base44.
